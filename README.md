# 🌱 FoodLoop
### Every Meal Deserves a Destination.

**FoodLoop** is a Java-based food waste management and redistribution system designed to reduce food wastage on college campuses.

It connects college messes and canteens with NGOs to help eligible surplus food reach people in need.

## ✨ Features
- 🍽️ **Food Tracking** – Record meals prepared, served and wasted.
- 🤝 **Food Donations** – List and claim surplus food.
- 🧠 **Smart Matching** – Recommend suitable NGOs for donations.
- ⏰ **Multithreading** – Monitor donation deadlines in the background.
- 📊 **Impact Dashboard** – Track donations and food waste statistics.

## 🛠️ Tech Stack
- **Language:** Java
- **Database:** MySQL
- **Connectivity:** JDBC
- **Concepts:** OOP, Collections, Multithreading, File Handling
